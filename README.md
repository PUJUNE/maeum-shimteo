# 마음쉼터

절·교회·성당·Company 사옥을 탭으로 오가며 머무는 3D 온라인 쉼터.

- 서버 없이 브라우저 안에서만 돈다. 접속이 끊길 일이 없고, 한 번 열면 서비스 워커가 저장해 두어 오프라인에서도 다시 열린다.
- 함께 있는 방문객은 머무는 느낌을 위해 브라우저가 그리는 가상의 인물이다.
- 조작 — 마우스·손가락으로 끌어 둘러보기, 바닥을 눌러 걷기, WASD·방향키로 걷기, 휠·두 손가락 벌리기·오른쪽 위 +/− 단추·+/- 키로 확대와 축소.
- 장소별 동작 — 절(합장·삼배·염주), 교회(기도·찬양·아멘), 성당(성호·무릎 꿇기·초 봉헌), Company 사옥(로비의 목례·커피·박수, 정문 밖 거리, 북쪽 공영주차장, 남쪽 교회와 그 앞 지상 주차장, 하천의 다리 두 곳까지 걷기).
- 소리는 모두 Web Audio 로 합성한다(목탁·범종·풍경·오르간·성가 흉내). 외부 음원·이미지 없음.
- 3D 엔진 three.js r160 (MIT) 을 `vendor/` 에 함께 둔다.

링크 `?place=temple|church|cathedral|ohc&room=1~30` 으로 장소와 방을 바로 고를 수 있다.
